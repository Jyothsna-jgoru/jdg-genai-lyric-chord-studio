# JDG GenAI Lyric-to-Chord Studio

Public Docker demonstration of the portfolio application. The first startup downloads the public FLAN-T5-small base model. Generation runs locally inside the Space, validates neural output, and uses the explicitly labeled deterministic theory fallback when necessary.

For the complete source, architecture, evaluation, limitations, and reproducibility instructions, see the linked GitHub repository.
